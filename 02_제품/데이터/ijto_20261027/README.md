## Oracle 저장 방식

세 JSON 전체를 `IJTO_DATA_SNAPSHOT.PAYLOAD`의 CLOB에 원문 그대로 보존함 출처 저장소·커밋·파일 경로·SHA-256·수집일을 함께 저장함 계절지수, 여러 해를 합친 시간대 비중, 관광지 후보, 카드 이용건수와 세부 고객군은 이 원문에서 확인할 수 있음

기존 화면이 사용하는 테이블에는 실제 특정 연월의 관측값만 추출함

| 대상 | 저장 내용 |
| --- | --- |
| `REGION` | 원천 방문 코드 10자리를 문자열 그대로 사용한 43개 읍면동 |
| `REGION_MONTHLY_STAT` | 구좌 방문 16행, 음식점 소비 44행 총 60행 방문은 만 명·소비는 억 원으로 정확히 환산 |
| `REGION_CONSUMPTION_STAT` | 구좌 음식점의 월별 내국인·외국인 소비 비중 88행 소수 둘째 자리 반올림 원래 소비금액은 JSON에 보존 |
| `DATA_SOURCE`·`DATA_VALIDATION_RESULT` | 방문·소비 출처 2개와 출처마다 검증 항목 5개 |

방문 자료는 2025년과 2026년의 1월부터 8월까지임 소비 자료는 고객군별 실제 금액을 더한 2023년부터 2025년까지의 36개월과 2026년 1월부터 8월까지임 내국인 비중에는 내국인 관광객과 도민을 포함하고 업종은 `RESTAURANT`로 저장함 다년 시간대 평균을 특정 연도의 관측값으로 저장하지 않음

`STAT_VALUE`는 소수 손실을 막기 위해 `INTEGER`에서 `NUMBER`로 확장함 예를 들어 493,209명은 49.3209만 명, 4,546,311,310원은 45.46311310억 원임 계절지수를 인원이나 금액으로 바꾸지 않고 없는 달은 0으로 채우지 않음
