# 기존 시안을 Figma Make에서 이어서 만들기

공식 안내 확인일: 2026-09-27

현재 준비된 자료는 [Figma Design 파일](https://www.figma.com/design/3g5xR8OkcV6sUclyGM5d30)과 로컬 HTML·CSS·JavaScript 시안임 이 문서는 Make 작업을 시작할 때 사용할 안내와 프롬프트이며, Make 앱 생성·기존 로직 자동 전송을 완료했다는 기록이 아님

## 사용할 수 있는 두 경로

| 경로 | 활용 방법 | 확인할 조건 |
| --- | --- | --- |
| Design 화면을 첨부해 Make에서 구현 | 실제 프레임을 프롬프트에 첨부하고 화면·동작을 순서대로 구현 | 계정에서 Make 사용 가능 여부와 AI 크레딧 확인 |
| 기존 저장소를 Make에 직접 연결 | Figma Beta에서 로컬 Git 저장소를 열어 실행 중인 앱의 코드를 편집 | Mac용 Figma Beta 앱, 비공개 베타 승인 계정, AI 기능 활성화, Git 저장소 접근 권한 필요 |

일반 Make는 기존 Design 프레임을 첨부해 시작할 수 있고 코드 편집기에서 직접 코드를 추가할 수 있음 프레임은 한 번에 하나씩 붙여 작업하는 방식이 권장됨 **Design URL만 프롬프트에 넣으면 해당 파일 내용을 가져오지 않으므로 실제 프레임을 첨부해야 함** 기존 코드의 동작은 Make 프로젝트에 적용한 뒤 따로 확인함 [Figma Make 공식 FAQ](https://help.figma.com/hc/en-us/articles/31722591905559-Figma-Make-FAQs)

기존 저장소에 직접 연결하는 기능은 현재 일부 사용자 대상 비공개 베타임 이 계정의 베타 승인 여부는 확인 전이며, 일반 Figma 플러그인 인증만으로 이 기능에 접근할 수 있다고 판단하지 않음 접근 가능한 경우 저장소를 열고 Make의 초기 설정 안내에 따라 미리보기를 실행함 [로컬 코드베이스 연결 공식 안내](https://help.figma.com/hc/en-us/articles/40775535020695-Make-in-your-local-codebase)

## 시작 프롬프트

Make에 **SCR-C-002 한눈에 보기 프레임을 실제로 첨부한 뒤** 사용함 다음 화면은 해당 프레임을 하나씩 추가하며 요청함 코드베이스 연결 경로에서는 아래 파일을 직접 참조하고, 일반 Make에서는 필요한 코드와 동작 설명을 함께 제공함

```text
첨부한 화면을 바탕으로 “제주 마케팅 캘린더”의 기존 웹 시안을 이어서 만들어줘.

이번 단계는 SCR-C-002 한눈에 보기와 공통 사이드바를 재현해줘.
화면의 한국어 명칭, 녹색 계열, Pretendard Variable, 여백과 카드 배치를 유지해줘.
사이드바는 접기·펼치기와 너비 조절, 작은 화면의 메뉴 열기를 기존 시안처럼 지원해줘.

전체 주요 화면은 로그인, 한눈에 보기, 지역 분석, 홍보 제안, 3개월 일정,
실행 기록·사용 결과, 근거 연결, 자료·기준 관리의 8개야.
후속 요청에서 각 프레임을 추가할게. 팝업·탭·오류를 포함한 21개 상태는
storyboards.json의 Screen ID, 사용자 행위→처리→결과 설명을 따라줘.

기존 동작은 02_제품/화면시안/app.js, 모양은 styles.css,
화면 구조는 index.html을 참고해줘. 이번에 제공된 코드와 프레임 범위에서 작업해줘.
예시 자료와 브라우저 저장을 사용하는 체험 시안의 범위를 유지해줘.

자료 없음, 입력 오류, 저장 실패 때 입력 보존, 미확보와 실제 0건의 구분을 유지해줘.

작업 후 이번에 구현한 화면·동작과 아직 확인하지 못한 항목을 구분해서 알려줘.
```

## 완료를 판단하는 기준

- 첨부한 프레임의 메뉴·입력창·버튼·조회 결과가 Make 미리보기에서 대응되는지 확인
- 선택한 화면의 입력·저장·이동·오류를 기존 웹 시안과 대조
- 주요 화면 8개와 Storyboard 21개를 유지하고 필수·선택 범위를 대조
- Design의 Prototype 연결은 화면 이동의 정의임 Make의 실제 입력·저장 로직은 별도로 확인

Figma Design에서는 144개 연결의 정의와 이동 대상을 검사했으며, 실제 클릭 재생 테스트는 아직 하지 않음 이 검사 결과를 Make 앱의 동작 검증으로 사용하지 않음
