# 제주 마케팅 캘린더 화면 시안

사용자가 제공한 로그인·대시보드·지역 분석·캘린더·상권 데이터·운영 관리 화면을 바탕으로 새로 만든 독립 UI 시안

## 열기

[index.html](index.html)을 브라우저에서 열어 사용함 빌드나 패키지 설치 없이 HTML·CSS·JavaScript와 포함된 글꼴 파일로 동작

로컬 서버를 사용하는 경우 이 폴더에서 다음 명령으로 실행할 수 있음

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

접속 주소: `http://127.0.0.1:8766/`

## 설계한 화면

| 화면 | 주요 변경 |
| --- | --- |
| 시안 시작 | 밝은 계절 표현, 사업체·서비스 운영자 두 역할, 실제 로그인과 체험 구분 |
| 한눈에 보기 | 지역의 흐름, AI 계획 도우미, 추천, 3개월 계획을 한 흐름으로 배치 |
| 지역 분석 | 방문·소비 전환, 비교 계산, 기간·단위·누락 표시, 표로 읽기 |
| 홍보 제안 | 시기·지역·이유 확인 후 바로 계획 작성 |
| 3개월 일정 | 월별 직접 추가, 제안 반영, 수정·삭제, 기록으로 이동 |
| 실행 기록 | 실행 여부·날짜·클릭·예약 입력, 미수집과 0 구분, 회고 초안 |
| 근거 연결 | 예시 온톨로지 관계 선택과 설명, 동등한 관계 목록 |
| 자료 둘러보기·관리 | 예시 자료 검색, CSV 내려받기, 서비스 역할의 검증 결과 시연 |

## 동작 범위

- Pretendard Variable과 밝은 테마를 모든 화면·폼·대화상자에 적용
- 계획과 기록을 현재 브라우저의 `localStorage`에 저장 새로고침 후 복원
- 동일 지역·같은 추천을 중복 추가하면 기존 계획 수정으로 연결
- AI 시연의 목표 선택으로 후보가 달라지고 상품명이 초안에 반영됨 선택한 정기 휴무일에 걸리면 예시 날짜를 다음 날로 조정
- 적용할 AI 시연 초안을 선택한 뒤 일정에 저장 초안을 보는 것만으로 저장하지 않음
- 근거 패널·메뉴의 키보드 조작, 모바일 메뉴 접기, CSV 다운로드 지원
- 사용 안내에서 초기 예시로 되돌릴 수 있음 초기화는 확인 후 진행

## 실제 서비스와의 구분

이 결과는 기존 Figma 파일을 수정한 것이 아닌, 화면 설계를 검토하기 위한 별도 로컬 시안

모든 지역 수치·사업체 정보·홍보안은 화면용 예시임 분석 기준은 2025년, 계획 대상은 2026년 10월부터 12월로 고정 예시 자료의 11월 소비값은 누락 상태로 유지

실제 LLM 호출·서버 인증·사업체별 권한·CSV 적재·온톨로지 저장소/추론은 미연결 역할 전환은 체험용 메뉴 전환이며 보안 기능이 아님 AI 기능은 정해진 예시와 조건 처리로 만든 인터랙션 시연임 실제 사업체 정보·개인정보·인증키는 입력하지 않음

실제 Figma Make 코드에 옮길 때에는 [디자인 기준](../../DESIGN.md)과 [온톨로지·에이전트 설계](../../03_에이전트/온톨로지_AI_결합_설계.md)를 함께 사용

## 검증 방법

`verify.cjs`는 기존에 설치된 Playwright와 Chrome을 사용하며 앱 의존성을 추가하지 않음 로컬 서버 실행 후 사용 가능한 런타임 경로를 환경변수로 지정해 실행

```sh
PLAYWRIGHT_MODULE=/path/to/installed/playwright \
CHROME_PATH=/path/to/chrome \
node verify.cjs
```

화면별 1440px·1024px·390px 검토, 실제 폰트 로드, OS 다크 설정에서 밝은 테마 유지, 계획 작성·수정·복원·중복 방지, 기록의 0/미수집 구분, 근거 패널, AI 시연 조건·적용, 자료 검색·다운로드, 역할별 화면, 저장 불가 상태를 검사함

최종 검증 결과와 캡처는 [화면 시안 검증 기록](../../06_증빙/화면시안/검증.md) 참조 테스트 스크립트의 실행은 실제 서비스의 품질·접근성 전체 인증을 뜻하지 않음
