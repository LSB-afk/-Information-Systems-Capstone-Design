# 제주 마케팅 캘린더 화면 시안

제주 비수기 상권 마케팅 캘린더의 화면과 사용자 흐름을 확인하는 HTML·CSS·JavaScript 시안

## 실행

이 폴더에서 기존 Python으로 실행

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

주소: `http://127.0.0.1:8766/`

## 화면과 역할

| 화면 | 주요 동작 |
| --- | --- |
| 로그인 | 역할 선택, 이메일·비밀번호 입력, 입력 오류 표시, 비밀번호 보기 전환 |
| 한눈에 보기 | 지역 방문 추이, 3개월 계획 요약, 간결한 홍보 제안과 상세 화면 이동 |
| 지역 분석 | 지역·연도 선택, 방문·계절 및 소비 비교, 자료 없음, 출처·단위·누락 표시 |
| 홍보 제안 조회 | 저장한 추천 기준에 맞는 제안 조회, 근거·출처 확인, 일정에 반영 |
| 3개월 홍보 일정표 관리 | 직접 계획 추가, 제안 반영, 수정, 삭제 확인·취소, 사용 기록으로 이동 |
| 사용 기록 입력 | 소요 시간·추천 채택·실제 활동·실행 날짜·클릭·예약·쿠폰 입력, 사용 결과 요약 |
| 자료·기준 관리 | 서비스 운영자 전용 CSV 양식 내려받기·파일 검증·등록, 추천 기준·근거 수정 |

- 로그인 세션 없이 주요 화면 주소로 접근하면 로그인으로 이동
- 사업체 운영자에게 자료·기준 관리 메뉴를 표시하지 않으며 직접 주소로 접근하면 한눈에 보기로 이동
- 서비스 운영자의 계획·기록 화면에는 권한을 부여받은 사업체를 표시
- 프로필과 로그아웃 버튼은 확인 팝업을 거쳐 로그인으로 이동하며, 취소하면 현재 화면과 세션을 유지
- 추천 근거와 출처·기준 팝업은 두 역할 모두 조회 가능
- 자료·기준 관리에는 자료 조회 표나 검색 메뉴를 두지 않음
- AI 계획 도우미와 보고서 초안은 이번 화면 범위에서 제외

## 주요 처리

- 계획과 기록은 현재 브라우저에 저장하고 새로고침 후 복원
- 동일 지역·같은 제안을 다시 담으면 기존 계획 수정으로 연결
- 계획·기록 저장 실패 시 기존 값과 입력창을 유지하며, 삭제 실패 시 계획과 연결된 기록을 복원
- 미확보 수치는 빈칸으로 유지하고 실제로 확인한 0건과 구분
- CSV는 파일 크기·확장자·필수 열과 다섯 검증 항목을 확인한 뒤 등록 가능
- 파일이나 메타데이터를 바꾸면 이전 검증을 무효화하며, 늦게 읽힌 이전 파일은 적용하지 않음
- CSV 등록 성공 시 등록한 자료 수와 완료 메시지를 바로 갱신
- 저장한 방문 감소 기준은 포함된 예시 방문값의 직전 월 대비 감소율에 적용하며, 조건에 맞는 제안이 없으면 빈 결과를 표시
- 출처·판단 이유·적용 조건 수정도 제안과 근거 패널에 반영하며, 저장 실패 시 기존 기준을 유지
- 메뉴 접기·펼치기, 너비 조절·초기화, 모바일 메뉴, 키보드 이동과 초점 복원 지원

## 구현 범위와 데이터 기준

이 시안은 실제 서버 인증과 사업체 권한 처리를 연결하기 전의 화면 검증용 구현임 로그인은 코드에 정의된 공개 테스트 계정을 확인하며 이메일·비밀번호를 저장하거나 서버로 전송하지 않음 화면의 역할 제한은 실제 서버 권한 검증을 대신하지 않음

계획·기록·추천 기준은 브라우저 저장소에 유지함 CSV 등록은 검증한 파일의 출처와 행 수를 저장하는 단계이며, 파일의 관측값을 서버에 적재하거나 분석 자료로 교체하는 처리는 미연결

지역 수치·사업체 정보·홍보안은 인공 예시임 분석 기준은 2025년, 계획 대상은 2026년 10월부터 12월임 11월 소비값은 미수집 상태로 유지하며, 지역 방문 집계를 개별 가게의 실제 고객 수나 미래 전망으로 해석하지 않음

실제 사업체 자료·개인정보·인증키는 입력하지 않음

## 검증

`review-regression.test.mjs`는 기존 Playwright와 설치된 브라우저 실행파일을 사용하며 앱 의존성을 추가하지 않음

```sh
NODE_PATH=/path/to/existing/node_modules \
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome-headless-shell \
node review-regression.test.mjs
```

2026-09-27 수정본에서 다음 10개 회귀 시나리오 통과

1. 비로그인 직접 접근 제한, 사업체 관리 화면 접근 제한, 출처 조회 유지
2. 서비스 관리 주소 호환과 관리 전용 화면
3. 제거한 화면·시연 버튼 접근 차단과 필수 근거 조회
4. 로그아웃 취소·확인과 세션 종료
5. 추천 기준 저장 후 제안 목록·근거 반영
6. 추천 기준 저장 실패 시 입력값과 기존 기준 보존
7. CSV 검증·재검증·등록·완료 메시지·등록 수 갱신과 잘못된 자료 차단
8. 계획 삭제 취소·저장 실패 복원·재시도·새로고침 복원
9. 내려받은 CSV 양식의 업로드·검증 호환
10. 한눈에 보기의 일정 요약과 간결한 제안에서 상세 이동

기존 검증 스크립트는 이전 화면·시연 기능을 전제로 하는 항목이 있어 이번 완료 근거로 사용하지 않음 위 검증은 실제 서버 연동이나 운영 환경 보안을 확인한 결과가 아님
