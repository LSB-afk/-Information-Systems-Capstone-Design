## 게시본과 다른 점

- `assets/index-DIzVD0S3.css`는 게시 사이트의 파일과 같음 (SHA-256 앞 16자리 `30ef6462772bd74d`)
- `assets/index-PS2rR3n-jejumap.js`는 게시 사이트의 `index-PS2rR3n-.js`(SHA-256 앞 16자리 `7c0cdfd0fe6e552e`)에서 지역 분석의 지도 함수 하나만 바꾼 파일임 바뀐 내용은 아래 '지역 분석 지도' 참고 브라우저가 예전 파일을 다시 쓰지 않도록 파일 이름을 바꿈
- `assets/jeju-map.css`는 지도 스타일을 위해 새로 더한 파일임
- `index.html`에서 바꾼 곳은 네 가지임
  - JS와 CSS 주소를 게시 사이트 주소에서 로컬 경로(`./assets/`)로 바꿈
  - 지도 스타일 파일(`./assets/jeju-map.css`) 연결을 더함
  - Figma 커뮤니티 배너 스크립트(`/__figma__/make_community_banner_v1.js`)를 뺌
  - 페이지 언어를 `lang="en"`에서 `lang="ko"`로 바꾸고, 번역하지 않음 표시(`translate="no"`, `<meta name="google" content="notranslate">`)를 더함 영어로 적혀 있으면 Chrome이 한글 화면을 자동 번역해 '제주'가 '일본', '비밀번호'가 '포스틱'처럼 바뀌어 보임
- 글꼴(Pretendard)은 게시본처럼 jsdelivr에서 불러오므로 인터넷에 연결되어 있어야 같은 글꼴로 보임

## 지역 분석 지도

게시본의 '지역을 선택해 비교해요' 카드는 타원 모양의 위치 개념도였음 팀이 제공한 제주 읍·면 지도 이미지를 따라 경계를 그린 지도로 바꿈

| 항목 | 내용 |
| --- | --- |
| 지도 내용 | 읍·면 12개 영역(제주시, 애월읍, 한림읍, 한경면, 대정읍, 안덕면, 서귀포시, 남원읍, 표선면, 성산읍, 조천읍, 구좌읍)과 우도·가파도·마라도, 섬 이름(추자도, 비양도, 차귀도) |
| 서귀포시 영역 | 참고 이미지처럼 중문과 서귀포시를 한 영역으로 그리고 이름만 두 곳에 표시함 |
| 강조 | 예시 자료가 있는 애월읍과 구좌읍만 연두색으로 칠하고, 고른 지역은 진녹색으로 바꿈 핀과 10월 방문값(만 명)을 지도 위에 표시함 |
| 선택 방법 | 지도의 애월읍·구좌읍을 누르거나 지도 아래 버튼을 누름 두 방법 모두 위쪽 '분석 지역' 선택과 같이 바뀜 키보드로는 아래 버튼을 씀 |
| 정확도 | 참고 이미지의 경계를 따라 단순화한 그림이라 실제 행정 경계·축척과 조금 다름 카드 설명에 '경계는 단순화해 표시'라고 적음 |

Figma Make에서 다시 게시하면 이 지도 변경은 사라짐 Make에도 같은 지도를 넣거나, 다시 가져온 뒤 지도 함수(`function ke()`)를 같은 방식으로 바꿔야 함

## 실행

저장소 최상위 폴더에서 기존 Python으로 실행

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory "02_제품/화면시안_Make"
```

주소: `http://127.0.0.1:8767/`

로그인 화면 아래의 '임시 계정' 상자에서 **계정 정보 채우기**를 누르면 고른 역할의 화면 확인용 계정이 입력됨 이메일·비밀번호를 서버로 보내지 않고, 계획과 기록은 현재 브라우저에만 저장함

번역된 글자로 보이면 Chrome 주소창의 번역 아이콘에서 '원본 보기'를 누르고 새로고침함

## 다시 게시했을 때 바꾸는 방법

1. 게시 사이트의 `index.html`과 그 안에 적힌 `assets/` JS·CSS 파일을 내려받음
2. 이 폴더의 `assets/` 파일을 새 파일로 바꿈
3. 위 '게시본과 다른 점'의 `index.html` 수정 세 가지를 다시 적용함
4. 로컬에서 화면을 열어 게시 사이트와 비교한 뒤 이 문서의 날짜와 SHA-256 값을 고침

## 확인한 것

- 로그인 화면을 게시 사이트와 같은 크기(1440×1000)로 나란히 비교해 같게 보임 '임시 계정' 상자와 비밀번호 안내도 같음
- '계정 정보 채우기'로 이메일과 비밀번호가 채워지고 사업체 운영자로 로그인됨
- 한눈에 보기의 '활용 사례'와 '실제 데이터 반영 현황', 홍보 제안의 월별 열과 '한 번에 담기'가 표시됨
- 한눈에 보기, 홍보 제안, 실행 결과 조회, 3개월 홍보 일정표, 지역 분석 화면이 콘솔 오류 없이 표시됨
- 지역 분석 지도: 지도의 구좌읍을 누르면 구좌읍이 선택되고 위쪽 '분석 지역'도 구좌읍으로 바뀜 아래 애월읍 버튼을 누르면 지도·버튼 상태(`aria-pressed`)·분석 지역이 함께 애월읍으로 바뀜 콘솔 오류 없음
- 지역 분석 지도는 데스크톱(1440×1000)과 휴대폰(375×812) 너비에서 카드 밖으로 넘치지 않음
- JS 파일에서 지도 함수 앞뒤의 내용은 게시본과 글자 하나까지 같음을 비교함
- 이번 게시본에서는 서비스 운영자 전용 화면을 다시 열어 보지 않았고, 화면 안의 버튼과 입력 동작을 하나씩 모두 눌러 보지는 않았음 지도 함수 밖의 코드는 게시본과 같으므로 동작도 게시본과 같다고 봄
