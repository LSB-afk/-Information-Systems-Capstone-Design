# 제주 마케팅 캘린더 화면 시안 (Figma Make 게시본)

Figma Make로 만든 화면을 게시 사이트에서 그대로 가져와 로컬에서 실행하는 폴더

## 출처와 버전

| 항목 | 내용 |
| --- | --- |
| 게시 사이트 | [blob-silver-16955234.figma.site](https://blob-silver-16955234.figma.site) |
| Figma Make 프로젝트 | [편집 파일](https://www.figma.com/make/AlZOwKZXABo7G6BkUhTG03/Start-Task) |
| 게시본 날짜 | 2026-09-27 (게시 사이트의 마지막 수정일) |
| 가져온 날짜 | 2026-10-11 |
| 크기 | 약 500KB (HTML 1개, JS 1개, CSS 1개) |

## 게시본과 다른 점

- `assets/index-Cy3nF8CL.js`와 `assets/index-CEpKENwd.css`는 게시 사이트의 파일과 같음 (SHA-256 앞 16자리: JS `d0df2f1b735f506a`, CSS `29ec36ac4f3f55c9`)
- `index.html`에서 바꾼 곳은 세 가지임
  - JS와 CSS 주소를 게시 사이트 주소에서 로컬 경로(`./assets/`)로 바꿈
  - Figma 커뮤니티 배너 스크립트(`/__figma__/make_community_banner_v1.js`)를 뺌
  - 페이지 언어를 `lang="en"`에서 `lang="ko"`로 바꿈 영어로 적혀 있으면 Chrome이 한글 화면을 자동 번역해 '제주'가 '일본', '비밀번호'가 '포스틱'처럼 바뀌어 보임
- 글꼴(Pretendard)은 게시본처럼 jsdelivr에서 불러오므로 인터넷에 연결되어 있어야 같은 글꼴로 보임

## 실행

저장소 최상위 폴더에서 기존 Python으로 실행

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory "02_제품/화면시안_Make"
```

주소: `http://127.0.0.1:8767/`

로그인은 [기존 화면 시안](../화면시안/README.md)과 같은 공개 테스트 계정을 사용함 이메일·비밀번호를 서버로 보내지 않고, 계획과 기록은 현재 브라우저에만 저장함

## 버전 주의

이 게시본은 화면설계서 `Red 화면설계서_20261003`에 담긴 Figma Make Version 8(2026-10-02 확인)보다 먼저 게시된 버전임 그래서 Version 8에서 더해진 아래 화면 요소는 이 폴더에 없음

- 홍보 제안의 '남은 제안 한 번에 담기', '월별 마케팅 제안 직접 추가'
- 한눈에 보기의 '활용 사례'와 '실제 데이터 반영 현황'

최신 Version을 다시 게시하면 같은 방법으로 `index.html`과 `assets/` 파일을 바꿔 넣음
