## 실행 전에 확인한 것

- `db/01_create_tables.sql`은 [ERD SQL](../../04_아키텍처/ERD/Red_ERD_Oracle.sql)의 1행부터 422행까지와 내용이 같음
- 두 SQL 파일과 서버 코드에 테이블을 지우는 문장(`DROP`, `TRUNCATE`)이 없음
- 계정이 비어 있어 기존 객체와 이름이 겹치지 않음 기존 테이블이나 데이터를 지우지 않음
- 테이블 이름은 ERD에 정의된 이름을 그대로 씀 `TBL_` 접두어 규칙과 다르며, 바꿀지는 팀 확인 후 ERD와 함께 정함 시퀀스는 `SEQ_` 규칙을 따름
- `application-local.properties`가 Git에 잡히지 않는 것을 `git status`와 `git check-ignore`로 확인함

## macOS에서 다시 실행하는 방법

[서버 프로젝트 README](../../08_개발/jeju-calendar/README.md)의 명령은 Windows PowerShell 기준임 macOS에서는 `mvnw.cmd` 대신 `sh mvnw`를 씀

```sh
cd 08_개발/jeju-calendar
export JAVA_HOME=<JDK 17 이상이 설치된 경로>
sh mvnw test
```

`src/main/resources/application-local.properties`에 접속 정보를 먼저 넣어야 DB 테스트가 실행됨 이 파일이 없으면 DB 테스트 32개는 건너뛰고 서버 시작 테스트 1개는 실패함
