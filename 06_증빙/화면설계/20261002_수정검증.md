## 반영한 변경

- 월별 홍보 제안, 월별 계획 직접 추가, 제안 일괄 담기와 중복 방지
- 계획 내용을 이용한 실행 기록 자동 채움과 실제 실행 내용 확인
- 활용 사례·결과(UC11), 데이터 반영 현황(UC12)을 기존 화면 안에 배치
- 메뉴 순서와 명칭, Screen ID, 관련 UC, 화면 경로, 취소·저장 후 호출 화면 복귀
- 소비 비교를 UC01에 연결, 사업체 운영자·서비스 운영자만 Actor로 사용
- 사례·효과 수치는 검증 전 예시로 표시하고, 데이터 25%를 실자료 적용률과 구분
- 제외한 보고서 초안은 구현 범위 페이지에만 명시
- 기존 공개 게시본 링크를 최신 Make 미리보기 링크로 교체

## 직접 확인한 표시와 재수정

전체 PDF 32쪽을 이미지로 렌더해 글자·표·캡처·번호 위치를 확인했다. 별도 검토가 6쪽부터 12쪽까지, 20쪽부터 30쪽까지를 점검했다.

검토 중 발견한 화면 목록의 구분 열 정렬, 일정 보기 버튼의 번호, 소비 비교 출처 번호, 사이드바 경계 조절 번호를 수정했다. 월별 제안은 넓은 화면으로 다시 캡처하고, 제안 카드 상세는 같은 Screen ID의 다음 쪽에서 확대했다. 사례·자료 현황도 같은 Screen ID 안에서 나누어 설명했다.

최종 수정에서 변경된 PDF 렌더는 12쪽뿐이며, 나머지 31쪽은 직전 검토 이미지와 바이트가 같다. 12쪽 ②는 실제 사이드바 오른쪽 경계로 옮긴 뒤 다시 확인했다.

## 확인 범위와 남은 항목

- Make 파일은 2026-10-02 비로그인 열람과 메뉴·버튼 이동을 확인했다. 별도 Figma Design Prototype 연결은 확인하지 않았다.
- PowerPoint 자동 PDF 출력은 AppleEvent 시간 초과로 완료되지 않았다. PDF는 원본 폰트를 지정한 LibreOffice로 생성했으며, PowerPoint 앱 안에서의 최종 렌더를 검증했다고 주장하지 않는다.
- 실제 서버 인증·권한·저장, CSV의 분석 데이터 적재, 실제 실행·성과 자동 수집은 시안에 연결되지 않았다. 이를 구현 범위 페이지에 명시했다.
- **원본 Use Case Diagram과 PROJECT의 최신 기능 최종 반영·대조는 남아 있다.** 제출 체크리스트 두 항목은 △로 유지했다.
- Figma Make 원본과 원본 다이어그램은 이번 작업에서 수정하지 않았다.
