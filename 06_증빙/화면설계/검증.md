## 기능 검증

시안의 기본 검사 15개와 동작·회귀 검사 28개 통과 [실행 로그와 범위](../화면시안/검증.md)에 기록

- 메뉴 접기·너비 조절·저장·모바일 및 체험 로그인
- 내외국인·시간대 소비, 빈 연도, 상시 출처·집계 기준
- 계획 소요 시간·추천 채택·실제 활동·날짜·클릭·예약·쿠폰 기록
- 계획·실행 비교·필수 사용 결과 요약과 F04 보고서 초안의 구분
- CSV 다섯 검사·검증 무효화·등록 차단·늦은 이전 파일 읽기 무시
- 추천 기준·근거 저장과 취소 보존, 저장 실패 후 입력 유지·재시도

## PDF 표시 확인

- Chrome으로 PDF 생성 시 Pretendard 실제 로드, 이미지 21개 로드, 요소·설명·표의 페이지 넘침 0개 확인
- PDFKit으로 최종 PDF 32쪽을 이미지로 렌더링해 전체 페이지 연락판 확인
- 소비 비교·사용 기록 입력·자료 관리·검증 확인표를 원래 크기로 열어 한글·번호·설명·여백 확인
- Figma 캡처는 1440×1120px이며 작은 입력 문구는 PDF 확대 또는 연결된 원본 PNG에서 확인 가능 긴 화면은 원본 Figma 프레임에서 아래 내용을 스크롤하도록 구성
- 문서의 로컬 링크·표 구조·번호 설명 일치는 검사함 Obsidian 읽기 화면은 직접 연결하지 못해 미확인

## Figma에서 남은 확인

전체 21개 프레임·캡처와 화면 ID 대응을 확인함 Prototype은 144개 연결 정의와 이동 대상 유효성을 검사했으며 실제 클릭 재생 테스트는 하지 않음 비로그인 요청은 CloudFront 403으로 차단되어 제출 후 열람 권한은 아직 검증하지 못함

Pretendard Variable을 유지하고 로컬 Figma 앱·FigmaAgent 실행 및 글꼴 캐시 9개 스타일 인식을 확인함 클라우드 MCP에서 글꼴 누락으로 표시되어 클라우드 텍스트 편집은 미검증 상태임 화면 캡처 확인과 글꼴 편집 가능 여부를 구분함
